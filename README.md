# تركي — الصفحات القانونية

هذه الصفحات منشورة لتكون الروابط الرسمية داخل تطبيق تركي:

- سياسة الخصوصية: `/privacy.html`
- الشروط والأحكام: `/terms.html`
- الدعم والمساعدة: `/support.html`

المصدر الأصلي داخل مستودع التطبيق في `apps/web-admin/src/app/{privacy,terms,support}`.
تُحدَّث النسخ هنا عند تغيير النصوص، وتُرفع إلى Supabase Storage أيضاً كنسخة احتياطية.
